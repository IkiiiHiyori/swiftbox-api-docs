# Welcome to SwiftBox Help Center

SwiftBox provides reliable parcel delivery services for businesses and individuals. Use this help center to create your first order, track shipments, manage billing, and integrate SwiftBox with your own systems.

[Get Started](getting-started.md){ .md-button .md-button--primary }

## Why Choose SwiftBox

### 🚀 Fast Nationwide Delivery

Ship parcels to any supported destination with predictable delivery windows. Our distribution network is designed to move shipments quickly and keep recipients informed.

### 📍 Real-Time Tracking

Track each shipment with detailed status updates, estimated delivery times, and location history. For automated updates, configure [webhook notifications](tracking.md#webhook-notifications).

### 🔒 Secure Handling

SwiftBox follows documented handling procedures from pickup through delivery. Each order is associated with a tracking number so you can monitor the shipment lifecycle from the dashboard or API.

!!! note
    New to SwiftBox? Start with the [Getting Started](getting-started.md) guide to create an account and place your first order.

## Support

Need help with an order, invoice, or API integration? Email [support@swiftbox.com](mailto:support@swiftbox.com) and include your order ID or tracking number when available.

For common account, payment, and plan questions, see the [Pricing & Billing FAQ](billing.md#faq).
